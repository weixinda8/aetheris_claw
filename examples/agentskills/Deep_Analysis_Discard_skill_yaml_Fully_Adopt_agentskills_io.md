### 4.3 弊处 3：失去 .skill.yaml 的一些特性 ⭐

**事实：**
- .skill.yaml 有一些企业级特性：
  - api_version、kind（Kubernetes 风格）
  - spec.security.sandbox_level
  - spec.implementation（内置技能）
  - 强类型的 returns 定义
- agentskills.io 可能没有完全对应的字段

**评估：**
- 可以映射到 agentskills.io 的 metadata 字段
- 可以扩展 agentskills.io（它支持自定义 metadata）
- 企业级特性可以作为扩展保留

**结论：** 可以解决，不是根本障碍。
