## 开发环境设置

### 前置要求

- Rust 1.70+
- PostgreSQL 14+
- Qdrant 1.0+
- Docker（可选，用于本地开发）

### 本地开发环境

1. 克隆仓库：
```bash
git clone https://github.com/aetheris/aetheris-skill-hub.git
cd aetheris-skill-hub
```

2. 安装依赖：
```bash
cargo check
```

3. 启动开发服务：
```bash
# 使用 Docker Compose 启动依赖服务
docker-compose up -d postgres qdrant

# 运行数据库迁移
cargo run -- migrate

# 启动开发服务器
cargo run
```

4. 运行测试：
```bash
cargo test
```

### 配置开发环境

复制并编辑 `.env.example`：
```bash
cp .env.example .env
```

关键环境变量：
```env
# 服务器配置
SERVER_HOST=127.0.0.1
SERVER_PORT=8080

# 数据库配置
DATABASE_URL=postgresql://aetheris_skill_hub:aetheris_skill_hub_password@localhost:5432/aetheris_skill_hub

# Qdrant 配置
QDRANT_URL=http://localhost:6333

# 可观测性配置
OTEL_ENABLED=false
PROMETHEUS_ENABLED=true
PROMETHEUS_PORT=9090
```

## 技能开发指南

### 技能格式

Aetheris 技能使用 YAML 或 JSON 格式。以下是一个基本示例：

```yaml
# skill.yaml
skill_id: com.example.websearch
name: Web Search
description: Search the web for information
version: 1.0.0
author: Example Corp
categories:
  - Search
  - Automation
tags:
  - web
  - search
  - information
call_mode: Text
permission_level: Public
priority: Medium

input_schema:
  type: object
  properties:
    query:
      type: string
      description: Search query
  required:
    - query

output_schema:
  type: object
  properties:
    results:
      type: array
      items:
        type: object
        properties:
          title: string
          url: string
          snippet: string

example_input:
  query: "What is Rust?"

example_output:
  results:
    - title: "Rust Programming Language"
      url: "https://www.rust-lang.org"
      snippet: "A systems programming language..."
```

### 技能元数据字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `skill_id` | String | ✅ | 技能唯一标识符（反向域名格式） |
| `name` | String | ✅ | 技能名称（最大 100 字符） |
| `description` | String | ✅ | 简短描述（最大 2000 字符） |
| `long_description` | String | ❌ | 详细描述 |
| `version` | String | ✅ | 语义化版本号 |
| `author` | String | ✅ | 作者名称 |
| `categories` | String[] | ✅ | 分类列表 |
| `tags` | String[] | ✅ | 标签列表（最多 20 个） |
| `call_mode` | String | ✅ | 调用模式（Text/Structured） |
| `permission_level` | String | ✅ | 权限级别（Public/Internal/Restricted/Admin） |
| `priority` | String | ✅ | 优先级（Low/Medium/High/Critical） |
| `input_schema` | JSON | ❌ | 输入 JSON Schema |
| `output_schema` | JSON | ❌ | 输出 JSON Schema |
| `example_input` | JSON | ❌ | 输入示例 |
| `example_output` | JSON | ❌ | 输出示例 |
| `dependencies` | String[] | ❌ | 依赖的其他技能 ID |

### 开发技能的最佳实践

1. **清晰的文档**
   - 提供详细的描述
   - 包含完整的输入输出示例
   - 说明使用场景和限制

2. **安全性**
   - 不要包含硬编码的密钥
   - 明确定义所需权限
   - 验证所有输入

3. **性能**
   - 合理设置超时
   - 优化资源使用
   - 提供性能指标

4. **测试**
   - 包含单元测试
   - 提供集成测试
   - 文档化测试用例

## 贡献流程

### 1. 找到要贡献的内容

- 查看 GitHub Issues
- 查看项目 Roadmap
- 提出新功能建议

### 2. Fork 仓库

```bash
# 在 GitHub 上 Fork 项目
# 然后克隆您的 Fork
git clone https://github.com/your-username/aetheris-skill-hub.git
cd aetheris-skill-hub
```

### 3. 创建特性分支

```bash
git checkout -b feature/your-feature-name
# 或
git checkout -b fix/issue-description
```

### 4. 进行更改

- 遵循代码规范
- 添加必要的测试
- 更新相关文档

### 5. 提交更改

```bash
git add .
git commit -m "feat: add new feature description"
# 或
git commit -m "fix: resolve issue #123"
```

提交信息格式：
- `feat:` 新功能
- `fix:` Bug 修复
- `docs:` 文档更新
- `style:` 代码格式
- `refactor:` 重构
- `test:` 测试相关
- `chore:` 构建/工具链

### 6. 推送并创建 PR

```bash
git push origin feature/your-feature-name
```

然后在 GitHub 上创建 Pull Request。

### 7. PR 审核流程

1. 自动化检查（CI）
2. 代码审核
3. 功能验证
4. 合并到主分支

## 代码规范

### Rust 代码规范

遵循 Rust 官方风格指南，使用 `rustfmt` 和 `clippy`：

```bash
# 格式化代码
cargo fmt

# 运行 Clippy 检查
cargo clippy -- -D warnings
```

### 命名约定

- **类型**：PascalCase（如 `SkillMetadata`）
- **函数/方法**：snake_case（如 `create_skill`）
- **常量**：SCREAMING_SNAKE_CASE（如 `DEFAULT_PORT`）
- **变量**：snake_case（如 `skill_id`）

### 错误处理

使用项目的 `SkillHubError` 类型：

```rust
use crate::utils::{Result, SkillHubError};

fn do_something() -> Result<()> {
    // ...
    Err(SkillHubError::NotFound("Skill not found".to_string()))
}
```

### 文档注释

为公共 API 添加文档注释：

```rust
/// 创建新技能
///
/// # 参数
/// - `skill`: 技能元数据
/// - `author_id`: 作者用户 ID
///
/// # 返回
/// 创建的技能 ID
///
/// # 错误
/// - `SkillHubError::Validation`: 验证失败
/// - `SkillHubError::Database`: 数据库错误
pub async fn create_skill(skill: SkillMetadata, author_id: Uuid) -> Result<Uuid> {
    // 实现
}
```

## 测试指南

### 运行测试

```bash
# 运行所有测试
cargo test

# 运行特定测试
cargo test test_name

# 显示测试输出
cargo test -- --nocapture

# 运行测试并生成覆盖率报告
cargo llvm-cov --html
```

### 编写测试

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_something() {
        // 准备
        let input = "test";
        
        // 执行
        let result = do_something(input);
        
        // 断言
        assert!(result.is_ok());
    }

    #[tokio::test]
    async fn test_async_function() {
        // 异步测试
    }
}
```

### 测试分类

- **单元测试**：测试单个函数/模块
- **集成测试**：测试多个模块的交互
- **端到端测试**：测试完整的用户场景
