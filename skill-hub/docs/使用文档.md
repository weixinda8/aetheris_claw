## 概述

Aetheris Skill Hub 是一个独立的技能发现、评分和分发服务，它允许：

- **用户**：发现、搜索、安装和评价技能
- **开发者**：提交、管理和更新技能
- **审核员**：审核技能以确保质量和安全性
- **管理员**：管理整个 Skill Hub 系统

### 主要特性

- 🔍 智能技能搜索（关键词、标签、分类）
- ⭐ 多维度技能评分系统
- 📥 一键安装和自动更新
- 🔒 企业级安全审核
- 📊 实时统计和可观测性
- 🔄 完整的版本管理

## 快速开始

### 前置要求

- PostgreSQL 14+
- Qdrant 1.0+（向量搜索）
- Rust 1.70+（如果从源码编译）
- Docker 和 Docker Compose（推荐）

### 使用 Docker Compose 快速启动

1. 克隆项目：
```bash
git clone https://github.com/aetheris/aetheris-skill-hub.git
cd aetheris-skill-hub
```

2. 配置环境变量：
```bash
cp .env.example .env
# 编辑 .env 文件，配置数据库和其他参数
```

3. 启动服务：
```bash
docker-compose up -d
```

4. 运行数据库迁移：
```bash
docker-compose exec skill-hub ./aetheris-skill-hub migrate
```

5. 访问服务：
- API 端点：http://localhost:8080
- 健康检查：http://localhost:8080/api/health
- 指标：http://localhost:9090/metrics

## 安装和部署

### Docker 部署

#### 使用官方镜像

```bash
docker pull aetheris/skill-hub:latest
```

#### 运行容器

```bash
docker run -d \
  --name skill-hub \
  -p 8080:8080 \
  -p 9090:9090 \
  -e DATABASE_URL=postgresql://user:pass@db:5432/skill_hub \
  -e QDRANT_URL=http://qdrant:6333 \
  aetheris/skill-hub:latest
```

### Kubernetes 部署

项目包含完整的 Kubernetes 部署配置文件：

```bash
cd k8s
kubectl apply -f configmap.yaml
kubectl apply -f secret.yaml
kubectl apply -f deployment.yaml
kubectl apply -f service.yaml
kubectl apply -f ingress.yaml
```

### 从源码编译

1. 安装 Rust：
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

2. 克隆并编译：
```bash
git clone https://github.com/aetheris/aetheris-skill-hub.git
cd aetheris-skill-hub
cargo build --release
```

3. 运行：
```bash
./target/release/aetheris-skill-hub
```

## 基本功能使用

### 用户认证

#### 注册新用户

```bash
curl -X POST http://localhost:8080/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "username": "myuser",
    "email": "user@example.com",
    "password": "securepassword123"
  }'
```

#### 登录

```bash
curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "myuser",
    "password": "securepassword123"
  }'
```

响应包含 JWT token，后续请求需要在 `Authorization` header 中使用：
```
Authorization: Bearer <your-token>
```

### 技能搜索和发现

#### 搜索技能

```bash
curl "http://localhost:8080/api/skills?search=web&category=automation&page=1&page_size=20"
```

#### 获取技能详情

```bash
curl http://localhost:8080/api/skills/<skill-id>
```

### 技能评分和评论

#### 查看技能评分

```bash
curl http://localhost:8080/api/skills/<skill-id>/rating
```

#### 发布评论

```bash
curl -X POST http://localhost:8080/api/skills/<skill-id>/reviews \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "rating": 5,
    "title": "Great skill!",
    "content": "This skill saved me a lot of time!"
  }'
```

### 下载和安装技能

#### 下载技能

```bash
curl http://localhost:8080/api/skills/<skill-id>/download \
  -H "Authorization: Bearer <token>" \
  -o skill.skill.yaml
```

#### 记录技能执行

```bash
curl -X POST http://localhost:8080/api/skills/executions \
  -H "Content-Type: application/json" \
  -d '{
    "skill_id": "<skill-id>",
    "version": "1.0.0",
    "success": true,
    "execution_time_ms": 150
  }'
```

## API 参考

### 认证端点

| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/auth/register` | POST | 注册新用户 |
| `/api/auth/login` | POST | 用户登录 |

### 技能端点

| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/skills` | GET | 列出/搜索技能 |
| `/api/skills` | POST | 创建新技能（草稿） |
| `/api/skills/:id` | GET | 获取技能详情 |
| `/api/skills/:id` | PUT | 更新技能 |
| `/api/skills/:id/download` | GET | 下载技能 |
| `/api/skills/executions` | POST | 记录技能执行 |
| `/api/skills/:id/reviews` | GET | 列出技能评论 |
| `/api/skills/:id/reviews` | POST | 发布技能评论 |
| `/api/skills/:id/rating` | GET | 获取技能评分 |
| `/api/skills/:id/submit-audit` | POST | 提交技能审核 |
| `/api/skills/:id/status` | PUT | 更新技能状态 |
| `/api/skills/:id/permission` | PUT | 更新技能权限 |
| `/api/skills/:id/audit-history` | GET | 获取审核历史 |
| `/api/skills/:id/automated-scan` | POST | 运行自动化扫描 |

### 审核端点

| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/audit/queue` | GET | 获取审核队列 |
| `/api/audit/stats` | GET | 获取审核统计 |
| `/api/audit/skills/:id/stages/:stage` | POST | 执行审核动作 |

### 系统端点

| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/health` | GET | 健康检查 |
| `/api/stats` | GET | 系统统计 |
| `/metrics` | GET | Prometheus 指标 |

## 常见问题

### Q: 如何重置管理员密码？

A: 使用环境变量 `INITIAL_ADMIN_USERNAME` 和 `INITIAL_ADMIN_PASSWORD` 在首次启动时设置初始管理员账户。

### Q: 技能审核需要多长时间？

A: 通常需要 3-5 个工作日，包括：
- 自动化扫描：< 5 分钟
- 初级审核：< 48 小时
- 高级审核：< 72 小时

### Q: 如何配置 Prometheus 监控？

A: 在 Prometheus 配置中添加：
```yaml
scrape_configs:
  - job_name: 'skill-hub'
    static_configs:
      - targets: ['localhost:9090']
```

### Q: 支持哪些技能格式？

A: Skill Hub 完全兼容 Aetheris 的技能格式（.skill.yaml 和 .skill.json）。

### Q: 如何报告安全问题？

A: 请通过 security@aetheris.dev 报告安全问题，我们会在 24 小时内回复。
