## 概述

本手册为 Aetheris Skill Hub 系统管理员提供完整的操作指南，包括系统安装、配置、用户管理、技能管理、监控和故障排除等内容。

### 管理员职责

作为 Skill Hub 管理员，您的主要职责包括：

- 系统安装、配置和维护
- 用户账户管理和权限控制
- 技能审核和质量保证
- 系统监控和性能优化
- 数据备份和灾难恢复
- 安全策略实施和合规检查

## 系统要求

### 硬件要求

| 环境 | CPU | 内存 | 存储 |
|------|-----|------|------|
| 开发/测试 | 2 核 | 4 GB | 50 GB |
| 生产（小型） | 4 核 | 8 GB | 100 GB |
| 生产（中型） | 8 核 | 16 GB | 500 GB |
| 生产（大型） | 16+ 核 | 32+ GB | 1+ TB |

### 软件要求

- **操作系统**：Linux（推荐 Ubuntu 22.04+ 或 Debian 11+）、macOS、Windows
- **数据库**：PostgreSQL 14+
- **向量数据库**：Qdrant 1.0+
- **容器运行时**：Docker 20.10+（推荐）
- **编排工具**：Kubernetes 1.24+（可选，用于生产环境）

### 网络要求

- 入站端口：
  - 8080：API 服务
  - 9090：Prometheus 指标（可选）
  - 4317：OpenTelemetry OTLP（可选）
- 出站端口：
  - 5432：PostgreSQL
  - 6333：Qdrant
  - 443：HTTPS（用于外部依赖）

## 安装和配置

### 生产环境安装

#### 1. 准备基础设施

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装 Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 安装 Docker Compose
sudo apt install docker-compose-plugin
```

#### 2. 配置环境变量

创建生产环境配置文件：

```bash
# /etc/aetheris-skill-hub/.env

# 服务器配置
SERVER_HOST=0.0.0.0
SERVER_PORT=8080
ENVIRONMENT=production

# 数据库配置
DATABASE_URL=postgresql://skill_hub_user:secure_password@postgres:5432/skill_hub_db
DATABASE_MAX_CONNECTIONS=50
DATABASE_MIN_CONNECTIONS=10

# Qdrant 配置
QDRANT_URL=http://qdrant:6333
QDRANT_COLLECTION_NAME=skills
QDRANT_VECTOR_SIZE=1536

# JWT 认证配置
JWT_SECRET_KEY=your-very-secure-jwt-secret-key-at-least-32-chars
JWT_EXPIRATION_HOURS=24
JWT_ISSUER=aetheris-skill-hub

# 初始管理员账户
INITIAL_ADMIN_USERNAME=admin
INITIAL_ADMIN_PASSWORD=change-this-immediately

# 可观测性配置
OTEL_ENABLED=true
OTEL_SERVICE_NAME=aetheris-skill-hub
OTEL_OTLP_ENDPOINT=http://otel-collector:4317
PROMETHEUS_ENABLED=true
PROMETHEUS_PORT=9090
PROMETHEUS_PATH=/metrics
```

#### 3. 使用 Docker Compose 部署

```bash
# 创建部署目录
sudo mkdir -p /opt/aetheris-skill-hub
cd /opt/aetheris-skill-hub

# 下载 docker-compose.yml
wget https://raw.githubusercontent.com/aetheris/aetheris-skill-hub/main/docker-compose.yml

# 复制环境变量文件
sudo cp /etc/aetheris-skill-hub/.env .env

# 启动服务
sudo docker-compose up -d

# 运行数据库迁移
sudo docker-compose exec skill-hub ./aetheris-skill-hub migrate

# 查看服务状态
sudo docker-compose ps
```

#### 4. 配置反向代理（Nginx）

```nginx
# /etc/nginx/sites-available/skill-hub

upstream skill_hub_backend {
    server 127.0.0.1:8080;
}

upstream prometheus_backend {
    server 127.0.0.1:9090;
}

server {
    listen 80;
    server_name skill-hub.your-domain.com;

    # 重定向到 HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name skill-hub.your-domain.com;

    # SSL 证书配置
    ssl_certificate /etc/letsencrypt/live/skill-hub.your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/skill-hub.your-domain.com/privkey.pem;

    # SSL 安全配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;

    # API 端点
    location / {
        proxy_pass http://skill_hub_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # 超时配置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # Prometheus 指标（限制访问）
    location /metrics {
        allow 192.168.0.0/16;
        allow 10.0.0.0/8;
        deny all;
        
        proxy_pass http://prometheus_backend;
        proxy_set_header Host $host;
    }

    # 安全头
    add_header X-Frame-Options "DENY" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
}
```

## 用户管理

### 用户角色

Skill Hub 定义了以下用户角色：

| 角色 | 权限 |
|------|------|
| `user` | 基本用户，可搜索、下载、评价技能 |
| `developer` | 可提交和管理自己的技能 |
| `auditor` | 可审核技能 |
| `admin` | 完全管理权限 |

### 创建管理员账户

首次启动时使用环境变量创建初始管理员：

```env
INITIAL_ADMIN_USERNAME=admin
INITIAL_ADMIN_PASSWORD=secure-password
```

### 用户管理 API

#### 列出所有用户

```bash
curl -X GET http://localhost:8080/api/admin/users \
  -H "Authorization: Bearer <admin-token>"
```

#### 更新用户角色

```bash
curl -X PUT http://localhost:8080/api/admin/users/<user-id>/role \
  -H "Authorization: Bearer <admin-token>" \
  -H "Content-Type: application/json" \
  -d '{"role": "auditor"}'
```

#### 禁用/启用用户

```bash
curl -X PUT http://localhost:8080/api/admin/users/<user-id>/status \
  -H "Authorization: Bearer <admin-token>" \
  -H "Content-Type: application/json" \
  -d '{"is_active": false}'
```

## 技能管理

### 技能状态

| 状态 | 描述 |
|------|------|
| `draft` | 草稿，仅作者可见 |
| `pending` | 审核中 |
| `published` | 已发布，所有用户可见 |
| `deprecated` | 已弃用，仍可使用但不推荐 |
| `blocked` | 已下架，无法使用 |

### 技能管理操作

#### 查看所有技能

```bash
curl "http://localhost:8080/api/admin/skills?status=all" \
  -H "Authorization: Bearer <admin-token>"
```

#### 更新技能状态

```bash
curl -X PUT http://localhost:8080/api/skills/<skill-id>/status \
  -H "Authorization: Bearer <admin-token>" \
  -H "Content-Type: application/json" \
  -d '{"status": "published"}'
```

#### 更新技能权限级别

```bash
curl -X PUT http://localhost:8080/api/skills/<skill-id>/permission \
  -H "Authorization: Bearer <admin-token>" \
  -H "Content-Type: application/json" \
  -d '{"permission_level": "Internal"}'
```

#### 下架技能

```bash
curl -X PUT http://localhost:8080/api/skills/<skill-id>/status \
  -H "Authorization: Bearer <admin-token>" \
  -H "Content-Type: application/json" \
  -d '{"status": "blocked", "deprecation_reason": "Security concern"}'
```

### 批量操作

```bash
# 批量发布技能
curl -X POST http://localhost:8080/api/admin/skills/bulk-publish \
  -H "Authorization: Bearer <admin-token>" \
  -H "Content-Type: application/json" \
  -d '{"skill_ids": ["id1", "id2", "id3"]}'
```

## 系统监控

### Prometheus 指标

Skill Hub 提供丰富的 Prometheus 指标，可通过 `/metrics` 端点访问。

#### 关键指标

| 指标名称 | 类型 | 描述 |
|----------|------|------|
| `skill_hub_api_requests_total` | Counter | API 请求总数 |
| `skill_hub_api_request_duration_seconds` | Histogram | API 请求延迟 |
| `skill_hub_api_errors_total` | Counter | API 错误总数 |
| `skill_hub_skills_total` | UpDownCounter | 技能总数 |
| `skill_hub_skills_published` | UpDownCounter | 已发布技能数 |
| `skill_hub_skills_downloaded_total` | Counter | 技能下载总数 |
| `skill_hub_skills_rated_total` | Counter | 技能评分总数 |
| `skill_hub_skills_executed_total` | Counter | 技能执行总数 |
| `skill_hub_database_queries_total` | Counter | 数据库查询总数 |
| `skill_hub_database_query_duration_seconds` | Histogram | 数据库查询延迟 |
| `skill_hub_audit_actions_total` | Counter | 审核动作总数 |

#### Prometheus 配置示例

```yaml
# prometheus.yml
scrape_configs:

    scrape_interval: 15s
```

## 备份和恢复

### 数据库备份

#### 自动备份脚本

```bash
#!/bin/bash
# /opt/backups/backup-database.sh

BACKUP_DIR="/opt/backups/postgres"
DATE=$(date +%Y%m%d_%H%M%S)
RETENTION_DAYS=30

mkdir -p $BACKUP_DIR

# 备份数据库
docker exec skill-hub-postgres pg_dump -U skill_hub_user skill_hub_db | gzip > $BACKUP_DIR/skill_hub_$DATE.sql.gz

# 删除旧备份
find $BACKUP_DIR -name "skill_hub_*.sql.gz" -mtime +$RETENTION_DAYS -delete

echo "Backup completed: skill_hub_$DATE.sql.gz"
```

#### 添加到 cron

```bash
# 编辑 crontab
sudo crontab -e

# 每天凌晨 2 点备份
0 2 * * * /opt/backups/backup-database.sh >> /var/log/skill-hub-backups.log 2>&1
```

### Qdrant 备份

```bash
#!/bin/bash
# /opt/backups/backup-qdrant.sh

BACKUP_DIR="/opt/backups/qdrant"
DATE=$(date +%Y%m%d_%H%M%S)

mkdir -p $BACKUP_DIR

# 创建 Qdrant 快照
curl -X POST "http://localhost:6333/collections/skills/snapshots"

# 下载快照
LATEST_SNAPSHOT=$(curl -s "http://localhost:6333/collections/skills/snapshots" | jq -r '.result[0].name')
curl "http://localhost:6333/collections/skills/snapshots/$LATEST_SNAPSHOT" -o $BACKUP_DIR/qdrant_$DATE.snapshot

# 保留 7 天
find $BACKUP_DIR -name "qdrant_*.snapshot" -mtime +7 -delete
```

### 恢复流程

#### 恢复 PostgreSQL

```bash
# 停止应用
docker-compose stop skill-hub

# 解压备份
gunzip /opt/backups/postgres/skill_hub_20240101_020000.sql.gz

# 恢复数据库
cat /opt/backups/postgres/skill_hub_20240101_020000.sql | docker exec -i skill-hub-postgres psql -U skill_hub_user skill_hub_db

# 重启应用
docker-compose start skill-hub
```

#### 恢复 Qdrant

```bash
# 上传快照
curl -X POST "http://localhost:6333/collections/skills/snapshots/upload" \
  -F "snapshot=@/opt/backups/qdrant/qdrant_20240101_020000.snapshot"

# 从快照恢复
curl -X PUT "http://localhost:6333/collections/skills/snapshots/recover" \
  -H "Content-Type: application/json" \
  -d '{"location": "qdrant_20240101_020000.snapshot"}'
```

## 安全最佳实践

### 认证和授权

1. **使用强密码策略**
   - 最小长度 12 字符
   - 混合大小写、数字、特殊字符
   - 定期轮换密码

2. **JWT 安全**
   - 使用强密钥（至少 32 字符）
   - 设置合理的过期时间（24 小时或更短）
   - 生产环境使用 HTTPS

3. **基于角色的访问控制（RBAC）**
   - 遵循最小权限原则
   - 定期审查用户权限
   - 记录所有权限变更

### 网络安全

1. **使用 HTTPS**
   - 配置 TLS 1.2+
   - 使用可信证书（Let's Encrypt）
   - 定期更新证书

2. **防火墙配置**
   - 只开放必要端口
   - 限制 SSH 访问
   - 使用 VPN 进行管理访问

3. **API 安全**
   - 实施速率限制
   - 验证所有输入
   - 使用安全头

### 数据安全

1. **加密静态数据**
   - 数据库透明加密（TDE）
   - 加密敏感字段（密码哈希）
   - 使用加密存储

2. **加密传输数据**
   - TLS 1.2+ 用于所有通信
   - 内部服务也使用加密

3. **数据脱敏**
   - 日志中不记录敏感数据
   - 测试环境使用脱敏数据

### 审计和监控

1. **启用审计日志**
   - 记录所有管理操作
   - 记录技能状态变更
   - 记录用户认证事件

2. **定期安全审计**
   - 每月审查访问日志
   - 每季度进行安全扫描
   - 每年进行渗透测试

3. ** incident response **
   - 制定安全事件响应计划
   - 定期演练响应流程
   - 及时报告和修复漏洞

## 故障排除

### 常见问题

#### 1. 服务无法启动

**检查清单：**
- 环境变量是否正确配置
- 数据库连接是否正常
- 端口是否被占用
- 日志中是否有错误信息

**诊断命令：**
```bash
# 查看服务状态
docker-compose ps

# 查看日志
docker-compose logs skill-hub

# 检查端口占用
netstat -tlnp | grep 8080
```

#### 2. 数据库连接失败

**检查清单：**
- PostgreSQL 是否运行
- 数据库 URL 是否正确
- 网络连接是否正常
- 防火墙是否阻止连接

**诊断命令：**
```bash
# 测试数据库连接
psql $DATABASE_URL

# 检查 PostgreSQL 状态
docker-compose ps postgres

# 查看 PostgreSQL 日志
docker-compose logs postgres
```

#### 3. Qdrant 连接失败

**检查清单：**
- Qdrant 是否运行
- 集合是否存在
- 向量维度是否匹配

**诊断命令：**
```bash
# 检查 Qdrant 健康
curl http://localhost:6333/healthz

# 列出集合
curl http://localhost:6333/collections

# 查看集合信息
curl http://localhost:6333/collections/skills
```

#### 4. API 请求超时

**可能原因：**
- 数据库查询慢
- Qdrant 搜索慢
- 网络延迟
- 资源不足

**解决方案：**
1. 检查数据库索引
2. 优化慢查询
3. 增加资源（CPU/内存）
4. 配置缓存
