# 用户指南

本指南将帮助您了解如何安装、配置和使用 Aetheris，从基本设置到高级功能。

## 目录

- [系统要求](requirements.md) - 运行 Aetheris 的系统要求
- [安装指南](installation.md) - 如何安装 Aetheris
- [配置指南](configuration.md) - 如何配置 Aetheris
- [基本使用](basic-usage.md) - 如何使用 Aetheris 的基本功能
- [IM 平台集成](im-integration.md) - 如何集成企业微信、钉钉、飞书等 IM 平台
- [Agent 管理](agent-management.md) - 如何管理和配置 Agent
- [Skill 管理](skill-management.md) - 如何管理和使用 Skill
- [故障排除](troubleshooting.md) - 常见问题和解决方案

## 快速开始

1. 确保您的系统满足 [系统要求](requirements.md)
2. 按照 [安装指南](installation.md) 安装 Aetheris
3. 按照 [配置指南](configuration.md) 配置 LLM 提供商
4. 启动 Aetheris 服务
5. 通过 IM 平台或 API 开始使用

## 支持

如果您遇到问题，请查看 [故障排除](troubleshooting.md) 指南或提交 [GitHub Issue](https://github.com/aetheris/aetheris/issues)。
